02How we would work

Six rules the plan sets for the team

They keep NowAI a software company, not an agency (target). target

  1. 01

    A fixed menu of roles

    Seven roles, the same for every client. No custom builds.

  2. 02

    Setup is configuration, not code

    A new client gets rules and settings, not new code.

  3. 03

    Count clients per deployment engineer

    From the first client. The model assumes 8. Fewer than 5 is the warning sign.

  4. 04

    Azerbaijani and Russian first

    Test sets, scripts and screens start in these two languages.

  5. 05

    Replay before live

    Every new rule is replayed on past weeks before it goes live.

  6. 06

    Label every number

    Model, target, estimate, synthetic, reported, verified or unknown. No claim without one.
